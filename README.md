## Tetris achievements

Tetris unlocks 13 run-only achievements for score milestones, line clears,
level progression, a new high score, and the Konami code. Reaching level 29
earns the classic Tetris milestone. Scoring 20,000 points in Hard mode only
earns the challenge achievement when the game was started at the highest
selectable level (15). Achievement popups fade in and out, and achievements
reset when you return to the title screen after a game over. After a game ends,
select **ACHIEVEMENTS** to view the current run's unlocked and locked awards;
use the on-screen back button or Escape to return to the game-over screen.

Press **F11** to toggle fullscreen. The game layout keeps its original size
and stays centered; only the background extends to fill the larger window.

During a Tetris game, press **C** to hold or swap the current piece (once per
piece, until the active piece locks). Press **Enter** to pause or resume.
